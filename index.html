Sketch Helper — Quick Reference

Data

Everything is stored locally on your device only. Use Export All to back up. Sketches are lost if browsing data is cleared, or when the site is closed in Incognito/Private mode (a warning shows automatically if detected).

Drawing

  • Tap the number field (auto-clears), type a length, tap a direction arrow.
  • 8 directions: up, down, left, right, and 4 diagonals.
  • Red dot = sketch start. Green dot = most recent point.
  • Undo removes only the active shape's last segment. Clear asks This Structure (just the active shape) or All Structures (confirms first).

Voice Commands

  • Mic button appears only if your browser supports it (not iPhone Safari).
  • Report a Bug (beside it) opens your email app with a description you type, sent as a report - no address shown in the app.
  • Say: "10 up", "25 upright", "12 down left", "undo", "new line", "circle" / "circle up" or "up circle" / "circle down" or "down circle", "snap on/off", "arc on/off", "save", "stop" (turns off listening).

Snap to Grid (on by default)

  • Rounds diagonal lengths to the nearest √2 (~1.41), stored as two whole-number legs (e.g. 5u5r) so no decimals are exported.

Semicircle Tools

  • Semicircle button: 1st tap = turn last segment into a dashed arc. 2nd+ tap = flip which side it bulges.
  • Height ↑ / ↓: only active once a segment has an arc.
  • Shows two numbers: straight length (by the line) and true arc length (by the arc).

Maintain Arc Length toggle:

  • On: Height ↑ / ↓ step the segment's own length by 1 unit (or one whole-number leg for a snapped diagonal), floored at 1 unit and capped at the number you originally typed. Height itself is derived from that length (rounded to a whole number) so the arc's true length stays as close as possible to the original number.
  • Off: segment length is fixed; Height ↑ / ↓ instead step the height itself by exactly 1 whole unit, floored at 1.

New Line

  • Closes the current shape with a line back to its start (visual only, not in the string), then starts a new shape.
  • Tap anywhere on any earlier shape to make it active again and keep drawing it.
  • New shapes auto-shift right as needed to stay 7 units clear of earlier ones.

Saving

  • Title + Save. New sketch → adds to list. Reopened sketch → updates it in place.

Sketches Tab

  • Tap a thumbnail to reopen and keep editing it.
  • Delete / Delete All — both confirm first.
  • Export All (CSV) — shares the file, or shows copyable text if sharing isn't supported. Includes a Structure column (1, 2, 3...) when a sketch has multiple shapes.
  • Sort By (top-right) — sort by Name, Date Created, or Date Saved, each ascending or descending.

Format

10u,10ur,10r,10dr,10d,10dl,10l,10ul — length + direction, comma-separated. A snapped diagonal is written as two legs with no comma (5u5r).
